# Russkiy — Image & Illustration Prompt Pack

> AI-image-generation prompts for artwork embedded in lessons, exercises, reading
> passages, and the gamification UI. Generated for visual **consistency**: every
> prompt begins with the same locked style prefix so the whole set looks like one
> cohesive product. **140 prompts** across 7 categories.

## How to use this pack

1. **Pick a generator** — Midjourney, DALL·E 3, Imagen, Ideogram, or Stable
   Diffusion / Flux all work. The prompts are self-contained: copy a whole
   `prompt` block in as-is.
2. **Aspect ratio** is given per image (Midjourney `--ar`, others use the
   nearest canvas size). Suggested `filename` mirrors a tidy `/public/img/…`
   layout you can drop straight into the web app.
3. **No text in images.** AI generators garble Cyrillic, and an education product
   can't ship misspelled Russian. Every prompt forbids text; any letters, words,
   or numbers are added **in-app as overlays** on top of the illustration. Grammar
   diagrams deliberately leave **blank label zones** for this.
4. **Keep recurring characters consistent** — reuse the same mascot/people prompts
   (or img2img / a seed / a character reference) so faces don't drift between
   images.
5. **Universal negative prompt** (append on generators that support it):

```
text, words, letters, numbers, captions, watermark, signature, logo, UI chrome, photorealistic, 3D render, harsh gradients, neon colors, oversaturation, clutter, busy background, extra fingers, distorted faces, garbled symbols, blurry, low-res
```

| Navy light | `#2e5a8f` | secondary navy, depth |

| Off-white | `#fafafa` | background |
